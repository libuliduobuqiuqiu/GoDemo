# Go 基础总览

> 状态：已整理并验证（语言核心规则）；验证环境：Go 1.25.5，模块语言版本 1.25。代码入口：[类型与接口示例](../../internal/godemo/)、[泛型示例](../../internal/gomanual/genericsdemo/)、[对应测试](../../test/manual/)。本页是阅读路线，运行时内部实现另见专题。

## 类型、声明与作用域

Go 是静态类型语言。`var` 声明的变量在没有显式初值时获得该类型的零值；`:=` 只能用于函数内部，并且同一作用域内重新声明时至少要引入一个新变量。`type New int` 定义新类型，`type Alias = int` 定义别名。导出标识符以大写字母开头，但仍需看其所在包和字段/方法的可见性。

参数按值传递；切片、映射、通道和接口的值中包含对其他数据的引用，复制这些值不等于深复制其引用的数据。数组长度属于类型，切片有长度和容量。不要依赖 `map` 遍历顺序，也不要把某个 Go 版本的切片扩容或哈希表布局当成语言保证。Go 1.24 更新了内置 map 的实现，正是避免依赖内部结构的例子。参见[语言规范](https://go.dev/ref/spec)及[Go 1.24 发行说明](https://go.dev/doc/go1.24)。

## 函数、方法与接口

`defer` 在外围函数返回前按后进先出执行。错误通常作为返回值向调用者传播；库函数不要以 `log.Fatal` 代替错误返回。具体处理方式见[错误处理专题](go_error.md)。

值接收器的方法属于 `T` 和 `*T` 的方法集；指针接收器的方法只属于 `*T` 的方法集。可以对可寻址的 `T` 值调用指针接收器方法，这是调用语法允许的自动取址，不等于 `T` 实现了要求该方法的接口。参见[方法与嵌入示例](../../internal/godemo/embedding_method_resolution_demo.go)和[语言规范的方法集](https://go.dev/ref/spec#Method_sets)。

接口由方法集和动态类型/值理解：只有动态类型与动态值都不存在时，接口值才等于 `nil`。一个装有 `(*T)(nil)` 的接口不等于 `nil`。类型断言的双返回值形式 `v, ok := x.(T)` 可避免失败时 panic。泛型约束中的类型集另见[泛型专题](go_generics.md)。

## 循环与并发

在本模块的 Go 1.25 语言版本下，`for` 中声明的循环变量按每次迭代分别创建；旧笔记中“闭包一定共享同一个循环变量”的说法适用于旧语言版本，不适用于这里。闭包若捕获循环外的共享变量，仍需自己同步。该变化见[Go 1.22 发行说明](https://go.dev/doc/go1.22)。

并发任务应明确停止信号与等待条件；通道、`context`、`sync.Cond` 的可结束示例见[并发控制实践](go_concurrency_practice.md)。调度器与 `GOMAXPROCS` 的版本边界见[并发与运行时](go_concurrency.md)。

## 模块、测试与阅读顺序

本仓库由根目录的 [`go.mod`](../../go.mod) 定义模块和语言版本。`internal/` 的导入受 Go 工具链限制；`go.sum` 记录已解析模块内容的校验和，但不是完整的依赖锁文件。先按问题阅读[文件操作](go_file.md)、[编译与逃逸](go_compile.md)、[GC](go_gc.md)，再用[测试专题](../advanced/go_testing.md)核对例子。

从仓库根目录验证本页连接的示例：

```bash
go build ./...
go test -timeout 20s ./test/manual ./test/godemo
```

这两条命令验证仓库示例可构建并运行；语言规则以 Go 1.25 的编译器和[规范](https://go.dev/ref/spec)为准。本页没有逐项证明所有运行时优化与性能结论。
